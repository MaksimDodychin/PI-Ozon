# PI OZON — дашборд на iPhone

PWA-приложение «Прайс индекс OZON». Хостится на GitHub Pages, обновляется
автоматически после каждого утреннего прогона и после каждой докрутки `пересчитать_после_загрузки.py`.

## Что нужно сделать один раз (10 минут)

### 1. Завести GitHub-аккаунт

1. Откройте https://github.com/signup
2. Email — ваш `dobyvankenoby@gmail.com` (или любой другой)
3. Username — любой свободный, например `massimo-pi` или `dobychin`.
   **Запомните его** — он попадёт в URL дашборда.
4. Подтвердите email.

### 2. Создать репозиторий

1. На https://github.com/new:
   - **Repository name**: `pi-ozon` (или любое — главное запомнить)
   - **Public** ✅ (для GitHub Pages бесплатно нужен public)
   - НЕ ставить галочки «Add README / .gitignore / license»
2. Нажать **Create repository**. Скопировать URL вида `https://github.com/<username>/pi-ozon.git`.

### 3. Подключить локальный репозиторий и запушить

В Терминале, **замените `<USERNAME>` и `<REPO>` на ваши**:

```bash
cd ~/Desktop/Massimo/Перестройка/Индекс\ цен/Дашборд\ iPhone
git remote add origin https://github.com/<USERNAME>/<REPO>.git
git push -u origin main
```

GitHub попросит логин/пароль. Вместо пароля нужен **Personal Access Token**:
- https://github.com/settings/tokens → **Generate new token (classic)**
- Note: `cli`, Expiration: `No expiration`, Scope: ✅ `repo`
- Сгенерировать → скопировать токен (он показывается один раз)
- Вставить как пароль при push (или: `git config --global credential.helper osxkeychain` — тогда кейчейн запомнит)

### 4. Включить GitHub Pages

1. На странице репозитория: **Settings → Pages**
2. **Source**: Deploy from a branch
3. **Branch**: `main` / `/ (root)` → **Save**
4. Через 1–2 минуты сверху появится URL вида
   `https://<USERNAME>.github.io/<REPO>/`

### 5. Установить на iPhone

1. Открыть этот URL в **Safari** на iPhone
2. Нижняя панель → **Поделиться** (квадрат со стрелкой)
3. **На экран «Домой»** → Добавить
4. На главном экране появится иконка «PI OZON»

Открывается как полноценное приложение, без браузерной обвязки.
Авто-обновление каждые 5 минут. Офлайн показывает последнее значение.

## Как это работает дальше

После каждого:
- `обновить_pi.py` (утренний прогон, cron `pi` в 06:30 МСК)
- `пересчитать_после_загрузки.py` (после каждой докрутки цен)

автоматически вызывается `публикация_дашборда.py`, который:
1. Запускает `дашборд_данные.py` → читает свежий xlsx.
2. Пишет `data.json` в эту папку.
3. `git commit && git push` → GitHub Pages подтягивает за ~30 секунд.

Massimo на iPhone видит свежие цифры через 5 минут (или сразу — pull-to-refresh кнопкой ↻).

## Если что-то сломалось

- **Открыли URL — белый экран**: подождать 1–2 минуты после первого push, GitHub Pages билдится.
- **На iPhone старые цифры**: нажать ↻ в правом верхнем углу или закрыть и открыть приложение.
- **Push не работает**: токен истёк → перевыпустить на https://github.com/settings/tokens.
- **Проверить вручную из терминала**:
  ```bash
  cd ~/Desktop/Massimo/Перестройка/Индекс\ цен/Дашборд\ iPhone
  python3 публикация_дашборда.py
  ```
